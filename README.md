# Тренировка

Дневник силовых тренировок: PWA для телефона, работает офлайн, данные хранятся только на устройстве.

План и решения — [docs/PLAN.md](docs/PLAN.md). Таблица упражнений и что вырезано из оригинальных описаний — [docs/exercises-review.md](docs/exercises-review.md).

## Запуск

Нужен Node.js 20+ (проверено на 24).

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # юнит-тесты (Vitest)
npm run build      # продакшен-сборка в dist/ (с service worker)
npm run preview    # проверить сборку: http://localhost:4173
```

Service worker (офлайн и установка) работает только в продакшен-сборке: `npm run build && npm run preview`.

## Публикация на GitHub Pages

PWA ставится на телефон только с HTTPS, поэтому нужен хостинг. GitHub Pages:

1. Создайте репозиторий на GitHub и отправьте код: `git remote add origin …` → `git push -u origin main`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. Workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml) при каждом пуше в `main` запускает тесты, собирает и публикует `dist/`.
4. Адрес будет `https://<имя>.github.io/<репозиторий>/`. Сборка использует относительные пути (`base: './'`), поэтому работает из подпапки.

Установка на телефон:
- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран Домой».
- **Android:** Chrome предложит «Установить приложение» (или меню ⋮ → «Установить»).

## Структура

```
src/domain/   чистые функции: формулы, единицы, даты, логика подходов (+ тесты)
src/data/     IndexedDB (Dexie): схема и миграции, репозитории, отмена, экспорт/импорт, начальная база (+ тесты)
src/ui/       экраны и компоненты React
scripts/      сборка базы упражнений и иконок
```

Пересборка базы упражнений (нужен `exercises.json` из free-exercise-db):

```bash
node scripts/build-seed.mjs path/to/exercises.json
```

Скрипт проверяет, что облегчённые альтернативы действительно легче исходных упражнений и что у каждого пучка дельт есть упражнения. При ошибке выходит с кодом 1.

## Данные и приватность

- Всё хранится в IndexedDB браузера на устройстве. Сети, аккаунтов, аналитики и трекеров нет.
- Резервная копия: «Ещё → Настройки → Экспорт JSON». Раз в неделю приложение напоминает о бэкапе.
- Внутри вес хранится в кг, время в секундах, даты в ISO 8601 UTC с часовым поясом. Единицы конвертируются только при отображении.
